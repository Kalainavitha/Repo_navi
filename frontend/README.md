# GenPlan

GenPlan is an intelligent project planning and team allocation dashboard for software delivery teams.

## Features

- Capture project stories, scope, and delivery constraints
- Generate realistic project plans from requirements and team capacity
- Visualize workstreams, dependencies, and scheduling assumptions
- Monitor project status and team allocation in a single workspace

## Running locally

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

## Build

```bash
npm run build
```
